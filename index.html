Current Research

Romanized Pashto NLP: Sentiment, Data, and Model Evaluation

My current research examines Romanized Pashto as it is used in everyday digital communication, including code-mixed Pashto–Urdu–English text written in Roman script. Rather than treating the work as a single model-training task, I am using it as a broader research setting to investigate data construction, annotation, dataset quality, model performance, and the differences between human- and AI-generated language data.

The work has developed into a series of connected experiments. Each study addresses a specific research question and contributes to a larger understanding of how NLP systems behave when working with limited, noisy, code-mixed language data.

Research programme: Dataset → Annotation → Data Quality → Model Training → Evaluation → Generalization → AI vs Human Data

01

Romanized Pashto Sentiment Analysis

Research · Ongoing (FYP)
Problem
Almost no labeled sentiment data exists for Romanized, code-mixed Pashto — a spelling-inconsistent variety with no orthographic standard.
Approach
Built a ~4,000-sentence manually annotated dataset (Positive/Negative/Neutral) from Facebook, Twitter, and WhatsApp, then fine-tuned a multilingual transformer for classification.
Technologies
XLM-RoBERTa, Google Colab (T4 GPU), FastAPI serving platform.
What was learned
An early 91% weighted F1 turned out to be inflated by a data-leakage bug in the train/validation split; correcting it produced a lower but trustworthy 87.8%. Reliable evaluation matters more than a high headline number.
Supervisor
Dr. Rafiullah

02

Pashto Sentiment Annotation Platform

Ongoing
Problem
Getting consistent sentiment labels from multiple annotators on a language with no spelling standard.
Approach
Built a multi-role web platform for annotators and reviewers to label Romanized Pashto text, to extend and quality-control the dataset beyond the initial ~4,000 sentences.
Technologies
FastAPI, HTML — migrated from an earlier Flask prototype.
What was learned
Migrating the tool from Flask to FastAPI and resolving a port conflict during integration was a reminder that applied NLP work is often systems engineering as much as modeling.

Pashto Language Learning / Flashcard System

Deployed · AI for Education
Problem

RAG / NLP Experiments

Experiment
Problem
Understanding, in practice, where retrieval-augmented systems tend to help or fail.
Approach
Built a full RAG pipeline — a portfolio chatbot grounded in a small custom knowledge base about my own background, skills, and projects.

Romanized Pashto Sentiment Dataset

Manually annotated · 3-class sentiment · code-mixed Roman-script Pashto
~4,000
Sentences
3
Classes
3
Source platforms
Manual
Annotation

Purpose: Training and evaluating sentiment models for a code-mixed, low-resource language variety with effectively no prior benchmark data.

Language: Romanized Pashto — code-mixed with Urdu and English, written in Roman script as used naturally by speakers online, distinct from standardized Pashto script.

Size: Approximately 4,000 sentences.

Structure: Sentence-level text paired with a Positive / Negative / Neutral label.

Annotation method: Manually labeled; sentences collected from Facebook, Twitter, and WhatsApp. A dedicated multi-role annotation platform was later built to extend and quality-control labeling.

Status: Used to train the current sentiment model; being actively expanded.

Availability: Accompanying fine-tuned model is public on HuggingFace Hub (abdul-razaq-ork/Romanized_Pashto_Sentiment); dataset release terms to be confirmed alongside the manuscript.
